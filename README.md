# AnyTV Player - iOS (Compose Multiplatform)

Independent iOS version of the AnyTV Player app, built with Kotlin Multiplatform and Compose Multiplatform.

## Structure

- `composeApp` — KMP shared UI and logic (common + ios)
- `iosApp` — iOS app wrapper (Xcode project generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen))
- `gradle` — version catalog and wrapper
- `.github/workflows/ios-build.yml` — GitHub Actions build pipeline

## Local build (requires macOS)

```bash
# Generate the Xcode project
cd iosApp
xcodegen generate

# Build the KMP framework and the iOS app
xcodebuild -project AnyTViOS.xcodeproj -scheme AnyTViOS -configuration Debug -destination 'generic/platform=iOS'
```

## Build on Windows

Windows cannot build iOS natively. Push the repository to GitHub and trigger the `ios-build.yml` workflow.

## Install on iPhone

1. Download the unsigned IPA artifact from GitHub Actions.
2. Use [Sideloadly](https://sideloadly.io/) or [AltStore](https://altstore.io/) on Windows with your Apple ID.
3. Re-sign the app every 7 days (or install via a paid Apple Developer account for 1 year).
